## Решения

- main и violet-shop-staging — канонический код и проверочное окружение. Старые базы не трогаем.
- HTML — исходники; два .mjs-файла генерируются. Проверка не перезаписывает рабочее дерево.
- Устаревший локальный server.mjs не входит в npm scripts и не эквивалентен Worker. Удалён; локальная разработка — Wrangler.
- Повреждённый scripts/google-sheets-sync.gs удалён из дерева; восстановление возможно через Git. Единственный исходник — scripts/catalog-sheets.gs. Ничего в Google Apps Script не развёртывалось.

- Медиа и базы данных не удаляются, миграции не запускаются в рамках этой чистки.

## Критерии проверки

1. npm ci и npm test успешно проходят в CI.
2. Сгенерированные модули совпадают с HTML, исходники UTF-8, синтаксис проверен.
3. Перед публикацией сверить целевой Worker и SHA.
4. Отдельно проверить реальные сценарии в браузере и Telegram; статические проверки их не заменяют.

- Проверка развёрнутого Apps Script, интеграций и актуальной конфигурации.

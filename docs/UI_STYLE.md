# Glass workspace UI

Визуальная система адаптирована из референса glassy dashboard без миграции проекта на React. Бизнес-логика и структура Worker сохранены.

- тёплая тёмная сцена на CSS-градиентах без внешнего фонового изображения;
- матовые стеклянные панели, тонкие световые границы и мягкая глубина;
- pill header и нижняя навигация;
- единый стиль витрины, age gate, карточек, форм и административной панели;
- мобильные breakpoints 900 и 520 px;
- reduced motion и reduced transparency сохраняются;
- пользовательские цвета превью магазина не перезаписываются.

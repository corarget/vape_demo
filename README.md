# VIOLET SHOP

Демонстрационная Telegram Mini App для каталога разрешённых розничных товаров.

## Что можно проверить

- категории представлены логотипом и короткой подписью;
- поиск и четыре варианта сортировки;
- выбранная сортировка и категория сохраняются после карточки товара и перезапуска;
- карточка товара с вариантами;
- корзина, оформление заказа и история;
- демо-панель магазина с подтверждением, отклонением и выдачей;
- пустой раздел «Акции»;
- адаптивный чёрно-серый интерфейс с фиолетовым неоном.
- автоматическая синхронизация каталога с листом `Catalog` в Google Sheets;
- группировка SKU в одну карточку с вариантами;
- товары без доступных вариантов всегда показываются после имеющихся и явно помечаются;
- фотографии загружаются из столбца `image_url`.

## Схема листа Catalog

Обязательные столбцы: `product_key`, `sku`, `category`, `name`, `option_label`, `price_byn`, `available`, `active`.

Дополнительные столбцы: `image_url`, `description`, `sort_order`. Для одного товара используйте одинаковый `product_key`, а каждый вариант размещайте отдельной строкой. Значения `available` и `active`: `TRUE`/`FALSE`.

По умолчанию сервер читает таблицу `1jNoG5NTnJZbNCx7iAq3S1CcuS0J1EDc8BWeW-nzKNtk` и лист с `gid=782461029`. Их можно заменить переменными `GOOGLE_SHEET_ID` и `GOOGLE_CATALOG_GID`. Таблица должна быть доступна серверу по ссылке; для закрытой таблицы в production следует использовать сервисный аккаунт Google.

Откройте `index.html` в браузере. Для локального сервера можно выполнить `node server.mjs` и открыть `http://127.0.0.1:3000`.

## Подключение к Telegram

1. Создайте тестового бота через BotFather.
2. Разместите приложение на HTTPS-хостинге.
3. Укажите HTTPS-адрес как Mini App URL в BotFather.
4. Открывайте приложение только через кнопку бота. В production сервер должен проверять подпись `Telegram.WebApp.initData`.

Демо хранит корзину и заказы в браузере. Для пилота магазина нужны серверное хранилище, Telegram-аутентификация, интеграция с таблицей разрешённого ассортимента и уведомления менеджеру.

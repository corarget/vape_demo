# VIOLET SHOP

Демонстрационная Telegram Mini App для каталога разрешённых розничных товаров.

## Что можно проверить

- категории представлены только логотипами без дублирующего списка;
- поиск и четыре варианта сортировки;
- выбранная сортировка и категория сохраняются после карточки товара и перезапуска;
- карточка товара с вариантами;
- корзина, оформление заказа и история;
- демо-панель магазина с подтверждением, отклонением и выдачей;
- пустой раздел «Акции»;
- адаптивный чёрно-серый интерфейс с фиолетовым неоном.

Откройте `index.html` в браузере. Для локального сервера можно выполнить `node server.mjs` и открыть `http://127.0.0.1:3000`.

## Подключение к Telegram

1. Создайте тестового бота через BotFather.
2. Разместите приложение на HTTPS-хостинге.
3. Укажите HTTPS-адрес как Mini App URL в BotFather.
4. Открывайте приложение только через кнопку бота. В production сервер должен проверять подпись `Telegram.WebApp.initData`.

Демо хранит корзину и заказы в браузере. Для пилота магазина нужны серверное хранилище, Telegram-аутентификация, интеграция с таблицей разрешённого ассортимента и уведомления менеджеру.

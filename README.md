# VIOLET SHOP — техническая документация

## Текущее окружение

- Каноническая ветка: `main`.
- Проверочное окружение: [violet-shop-staging](https://violet-shop-staging.platondran.workers.dev/).
- Конфигурация: `wrangler.jsonc`; привязка базы — `DB`, база — `violet-shop-staging-db`.
- Отдельный медиасервис: `violet-shop-media`. Не удалять без проверки зависимостей.
- Старые окружения и базы не являются частью канонического процесса сборки. Их данные нельзя удалять или переносить без отдельной ревизии.

## Разработка

Node.js 22, npm и зафиксированные зависимости из package-lock.json.

```sh
npm ci
npm run embed
npm test
npm run dev
```

После редактирования HTML необходимо выполнить `npm run embed` и закоммитить исходный HTML вместе с генерируемым модулем. CI проверяет кодировку, наличие статических ресурсов, соответствие генерируемых файлов исходникам и синтаксис JavaScript. CI также проверяет регрессии HTTP, прав доступа и конфигурации, применяет миграции на чистой локальной D1 и выполняет dry-run сборку Wrangler. Это не end-to-end тесты в Telegram.

Публикация вручную (`npm run deploy`) запускает проверки до Wrangler. Перед изменением базы проверьте имя Worker, привязку DB и целевое окружение. Не запускайте миграции автоматически при обычном обновлении кода. Секреты хранятся вне Git.

## Состояние и ограничения

- Google Sheets содержит два листа данных: Товары и Категории. D1 хранит данные приложения и настройки.
- Текущий код читает таблицу; полноценная двусторонняя синхронизация не подтверждена. Старый альтернативный Apps Script удалён из дерева, история сохранена в Git.
- Существование кода не означает, что интеграции протестированы в работающем Telegram Mini App.
- Коммерческое использование требует отдельной проверки законодательства, возрастных ограничений и правил платформы.
- Старый документ [WHITE_LABEL_SETUP.md](docs/WHITE_LABEL_SETUP.md) описывает предполагаемый процесс, а не проверенную готовность.

См. [инвентаризацию этапа 1](docs/STAGE_1.md), [контракт данных](docs/DATA_MODEL.md) и [аудит этапа 2](docs/STAGE_2.md).
